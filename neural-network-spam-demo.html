How a Neural Network Learns to Spot Spam

Pick a fictional email and follow its clues through a tiny network. Then change the weights and see which mistakes change.

From clues to a spam score

The network sees two numbers. One counts the links and the other records whether the email sounds urgent. Its hidden layer combines those clues, and its output turns the result into a score between 0 and 1.

1. Inputs

Links
Urgent wording

2. Hidden layer

Link signal
Links plus urgency

Each unit combines inputs, then replaces any negative result with zero.

3. Output

A score of 0.500 or higher triggers a spam flag.

See the calculations

The first hidden unit computes max(0, 0.70 × links − 0.65). The second computes max(0, 0.25 × links + 1.10 × urgency − 0.90), where urgency is 1 for yes and 0 for no. The weighted sum of the two hidden values, minus 1.60, passes through a sigmoid to make a score between 0 and 1.

Compare the four examples

Reduce the weight on links plus urgency to 0.5. Watch what happens to the password reset and the phishing email. Both have the same inputs, so the model gives them the same score even though their true labels differ.

What additional clue could help the model tell these messages apart? One possibility is whether the link leads to the service’s known domain. A team would need to test that feature on separate labeled messages.

What training changes

Here, you set two weights by hand. During supervised training, the network scores each example, a loss function compares that score with the known label, and an optimizer updates weights to reduce the loss. The demo’s four examples are illustrations. To estimate how well a real filter works on new emails, evaluate it on labeled data it did not train on.
